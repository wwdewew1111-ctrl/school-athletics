# Новости и синхронизация

В админ-панели откройте вкладку «Новости». Можно создавать черновики, публиковать и редактировать новости, прикрепить одно изображение JPEG/PNG (до 10 МБ), повторять синхронизацию и удалять новость с сайта. Дата носит информационный характер; публикация при установленном флажке происходит сразу. При удалении новости записи в соцсетях остаются.

Автоматическая отправка выполняется после сохранения опубликованной новости, отдельно для VK и Telegram. Результат и идентификаторы сообщений отображаются в админ-панели. Если запрос закончился ошибкой или сеть недоступна, новость на сайте сохраняется. Кнопка повторной синхронизации запускает отправку повторно; если API принял создание, но ответ с ID был потерян, перед повтором проверьте соцсеть вручную, чтобы не создать дубликат.

## Настройка через админ-панель

Во вкладке «Новости» раскройте «Настройки публикации в VK и Telegram». Укажите числовой ID сообщества VK без минуса и токен VK; для Telegram — ID канала (например, `-100…`) или `@username` и токен бота. Можно настроить только одну соцсеть. Сохраните настройки. Токены повторно не отображаются: пустое поле сохраняет прежний токен, новый текст заменяет его, а флажок удаляет. Не выбирайте удаление и замену одного токена одновременно. После настройки для ранее опубликованных новостей нажмите «Повторить синхронизацию» у каждой новости. Перед повтором проверьте, не появилась ли запись в соцсети: если ответ API был потерян, повтор может создать дубликат.

Токены и идентификаторы сохраняются в файле `school-athletics-social-settings.json` в **родительском каталоге проекта**, вне каталога сайта. При переносе сайта обеспечьте, чтобы этот каталог не был доступен через веб-сервер, а пользователь PHP мог создавать и изменять файл; ограничьте доступ к нему и резервным копиям средствами ОС. Токены хранятся в этом файле в открытом виде, поэтому доступ к файловой системе и бэкапам нужно ограничить. На Unix приложение пытается установить права `0600`; на Windows настройте ACL вручную. Не добавляйте файл с токенами в репозиторий. Используйте HTTPS и надёжный пароль администратора; любой авторизованный администратор сможет заменить токены. При переносе проекта перенесите защищённый файл отдельно или заново заполните настройки.

## Альтернатива: переменные окружения

Для работы API серверу PHP нужны расширения `curl` и `openssl`, проверка сертификатов TLS и доступ в интернет. Вместо формы можно задать переменные окружения процесса веб-сервера:

- `NEWS_VK_TOKEN` — пользовательский токен VK с правами для публикации от имени сообщества и разрешением `photos` для загрузки фото (VK может выдавать его по запросу). Точные доступные права зависят от актуальных правил VK.
- `NEWS_VK_GROUP_ID` — числовой ID сообщества без знака минус.
- `NEWS_TELEGRAM_TOKEN` — токен бота Telegram.
- `NEWS_TELEGRAM_CHAT_ID` — ID канала (например, `-100…`) или `@username`. Бот должен быть администратором канала с правами публикации и редактирования.

Настройки, сохранённые в админке, имеют приоритет перед соответствующими переменными окружения, в том числе при удалении токена или очистке ID. Если значение ещё не задавали через форму, используется переменная окружения. После изменения переменных может понадобиться перезапуск веб-сервера; после изменения настроек через форму он не требуется. Проверьте статус тестовой публикации. Если ID сообщества/канала изменится, старые публикации не переносятся автоматически; синхронизация таких новостей останавливается во избежание изменения чужих записей.

Telegram ограничивает подпись к фото 1024 символами, а текстовое сообщение — 4096. Тип уже отправленного сообщения (фото или текст) нельзя заменить другим через редактирование: при добавлении первой фотографии или удалении последней появится ошибка, требующая ручного решения. Изменение текста и замена одной фотографии другой выполняются через API. VK также может ограничивать редактирование, права токена и доступность методов; сообщение об ошибке показывается в админке. Сообщения вида «message is not modified» считаются успешной синхронизацией.
