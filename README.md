# School Athletics

Исходный код сайта спортивной школы на PHP и SQLite.

## Локальный запуск

Требуются PHP с расширениями PDO SQLite и Fileinfo. Для публикации новостей в соцсетях также необходимы cURL и OpenSSL; настройки описаны в `NEWS_SETUP.md`.

Из каталога проекта запустите:

```powershell
php -S 127.0.0.1:8080 -t .
```

Откройте `http://127.0.0.1:8080/`. При первом запуске приложение создаёт SQLite-базу и каталоги загрузок; процесс PHP должен иметь права на запись. Созданная база содержит начальные демонстрационные данные, а не содержимое существующего сайта.

## Данные и безопасность

Рабочая база `includes/database.sqlite`, каталог `uploads/`, журналы и локальные настройки исключены из Git: они могут содержать данные пользователей или секреты. Для полного восстановления существующего сайта необходимы отдельные защищённые резервные копии базы и загруженных файлов, включая изображения новостей из соседнего каталога `school-athletics-news-uploads`. Настройки соцсетей хранятся отдельно; подробности — в `NEWS_SETUP.md`.

**До размещения в интернете** настройте веб-сервер так, чтобы база, служебные файлы, резервные копии и файлы настроек не были доступны посетителям. Репозиторий содержит хеш пароля администратора в исходном коде `admin/index.php`: ограничьте доступ к репозиторию и замените пароль перед развёртыванием. Встроенный сервер PHP предназначен только для локальной разработки.
