# Обновление ссылки на социальную сеть

Ссылка в разделе «Основные сведения» хранится в рабочей базе SQLite и не переносится через Git автоматически. Создайте защищённую резервную копию базы, затем из корня сайта запустите:

```sh
php migrate_social_max.php --apply
```

Без `--apply` команда только показывает предполагаемое изменение. Миграция распознаёт исходное поле с ВКонтакте и Telegram, поле только с ВКонтакте и уже обновлённое поле; при другом содержимом она ничего не меняет и предлагает исправить поле через админку. Повторный запуск безопасен. Настройки и автоматическая публикация в Telegram при этом не меняются.
